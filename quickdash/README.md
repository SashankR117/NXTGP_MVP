# QuickDash App Directory

This directory contains the Next.js application for **QuickDash MVP**.

For full project architecture, features overview, database schemas, and grader walkthroughs, please refer to the main repository [README.md](../README.md) and [architecture.md](../architecture.md).

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
